# Examples

| Program | Shows |
|---------|-------|
| `queens.hs` | list comprehensions, the list monad (N-queens) |
| `sieve.hs` | `accumArray` (sieve of Eratosthenes) |
| `lcs.hs` | lazy arrays for dynamic programming (longest common subsequence) |
| `knapsack.hs` | lazy dynamic-programming tables |
| `wordfreq.hs` | `Data.Map.Strict` and sorting |
| `wordcount.hs` | `interact`, `printf` -- run with `< somefile` |
| `grid_bfs.hs` | parsing a grid into a `Map`, breadth-first search -- run with `< maze.txt` |
| `life.hs` | Conway's Game of Life with `Data.Set` |
| `calculator.hs` | an interactive calculator: tokenizer, parser, evaluator, `Either` for errors |

Run any of them with `husk examples/NAME.hs`.
